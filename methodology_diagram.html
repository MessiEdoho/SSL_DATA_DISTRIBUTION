Study design · single-channel mouse EEG

Self-supervised representation learning under varying data distributions for artefact-robust seizure detection

Reusing the baseline Multi-Scale TCN (M3) encoder · five runs × two adaptation protocols · false-alarm reduction on unlabelled artefacts
1
Input & data distributions
Segments are already preprocessed in the baseline study — preprocessing is not part of this work.
  • Single-channel mouse EEG, 500 Hz, 5 s windows, 50% overlap, robust z-scored
  • D0 proximity-aware downsampled (~220k; near-seizure-heavy)
  • D_full full unlabelled corpus (~33M; all artefacts)
  • D_broad broadened background (D0 + more far/artefact)
→
2
SSL pretraining — masked EEG autoencoder
  • Mask contiguous spans → reconstruct the signal
  • Trains the encoder only (Multi-Scale TCN / M3); decoder discarded
  • Monitored by reconstruction loss on validation
  • R1 ← D0  ·  R2R3 ← D_full
  • SSL hyperparameters fixed & disclosed (not tuned)
→
3
Downstream adaptation — two protocols
  • Attach linear classification head
  • P1 Frozen (linear probe): encoder locked, head only
  • P2 Full fine-tune: encoder + head end-to-end
  • Fine-tune data: D0 (R1, R2) or D_broad (R3, R4)
  • Recipe from M3: AdamW, cosine LR, BCEWithLogits, early stop on val macro-F1
→
4
Post-processing
  • Fixed ordered pipeline on probabilities:
  • 1. Probability smoothing (window = 3)
  • 2. Minimum-event filtering
  • 3. Refractory-period merging (30 s)
  • 4. Maximum-duration filtering (120 s)
  • Fixed decision P > 0.5 — no threshold tuning
  • Min-event {10,15,20,25,30}s; operating point from Recall-vs-FAR/hr Pareto (bottom-right = ideal)
→
5
Evaluation & representation analysis
  • Layer 1 standard metrics — segment + event level
  • Layer 2 artefact-proxy stratified FAR (stratum A vs control B)
  • Layer 3 embedding analysis — UMAP/t-SNE + seizure-vs-artefact probe AUROC + silhouette, across R0–R4
