 GLOBAL BUILD DECISIONS
--------------------------------------------------------------------------------
  * VENDOR the baseline encoder (tcn_utils.MultiScaleTCN) + eval_utils.py as a
    PINNED COPY into src/vendor/ (record source commit hash). Not imported live
    -> repo self-contained, encoder cannot drift from R0.
  * Every stage has a SLURM .sh wrapper, matching the DL_WITH_SSL_GA convention.
  * Deterministic seeding (seed 42).
  * VERTICAL SLICE FIRST: get R1 end-to-end (SSL pretrain -> fine-tune -> cache
    predictions -> one metric) and verify BEFORE scaling to R2-R4 and adding
    evaluation Layers 2/3.
  * Runs DEVELOPED here: R1, R2, R3, R4. R0 is reused from the parent project.
